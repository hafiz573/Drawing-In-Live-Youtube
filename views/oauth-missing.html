Konfigurasi server

Login Google belum aktif.

Server ini belum punya kredensial OAuth, jadi tombol login tidak bisa dipakai. Setelnya sekali saja:

1 — Bikin OAuth client

  • Buka Google Cloud Console → Credentials.
  • Aktifkan YouTube Data API v3 di menu Enabled APIs & services.
  • Create credentials → OAuth client ID → Web application.
  • Di Authorized redirect URIs, isi persis: http://localhost:3000/auth/google/callback

2 — Isi file .env

  • GOOGLE_CLIENT_ID=…
  • GOOGLE_CLIENT_SECRET=…
  • OAUTH_REDIRECT_URI=http://localhost:3000/auth/google/callback

3 — Jalankan ulang

docker compose up -d --build

Selama aplikasi masih berstatus Testing di Google, hanya akun yang kamu daftarkan sebagai Test user di OAuth consent screen yang bisa login. Panduan lengkap ada di README.md.
